# 📊 Dashboard BI -Analyse des Ventes, Satisfaction Client et Recouvrement

## 🎯 Objectif
Ce projet simule un cas métier complet dans les secteurs e-commerce et recouvrement. Il permet de suivre les ventes, la satisfaction client, les stocks et les encaissements, avec une approche Agile et orientée décision.

## 🌀 Méthodologie Agile
Le projet a été mené selon une logique Agile (Scrum) :
- Structuration du backlog en User Stories
- Organisation en 3 sprints avec livrables progressifs
- Revue et ajustement à chaque étape
- Documentation métier intégrée

## 🧩 Backlog (extraits)

- *En tant que responsable commercial, je veux visualiser les ventes par jour pour anticiper les pics de demande.*
- *En tant que manager CRM, je veux connaître la répartition des avis clients pour améliorer l’expérience.*
- *En tant que responsable recouvrement, je veux segmenter les encaissements par source pour prioriser les relances.*

## 📆 Sprints & Livrables

### Sprint 1 -Modélisation & KPIs
- Table calendrier
- Relations entre tables
- Graphique des ventes par jour
- KPI : total ventes, moyenne journalière, satisfaction positive

### Sprint 2 -Prévision & Filtres
- Prévision des ventes sur 5 jours
- Filtres dynamiques (jour, canal, période)
- Amélioration UX (infobulles, couleurs)

### Sprint 3 -Recouvrement & Documentation
- KPI encaissements
- Graphique par source et ancienneté
- README complet + synthèse métier

## 🛠️ Technologies utilisées
- Power BI Desktop & Service
- DAX (segmentation, KPI, prévision)
- Power Query (nettoyage, transformation)
- Données simulées (e-commerce, CRM, recouvrement)
