# 📊 Nike Sales & Stock Dashboard – Power BI

Ce projet présente un tableau de bord interactif réalisé avec Power BI pour analyser les performances commerciales de Nike. Il intègre les ventes, les prévisions, les stocks et la répartition géographique des produits.

## 📌 Objectif

Fournir une vue synthétique et opérationnelle des performances produits pour aider à la prise de décision stratégique.

## 🔍 Contenu du rapport

- Suivi des ventes mensuelles et prévisions
- Analyse du stock par catégorie et par pays
- Indicateurs clés : revenus, quantités vendues, MTM
- Visualisations dynamiques : cartes, graphiques combinés, KPI

## 🛠️ Technologies utilisées

- Power BI Desktop
- DAX (Data Analysis Expressions)
- Modélisation de données relationnelles

## 📁 Fichiers inclus

- Rapport Power BI (.pbix)
- Table de dates personnalisée
- Données de ventes et de stock (extrait)
