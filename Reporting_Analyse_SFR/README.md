# 📘 Mission Data Analyst – Reporting SFR

## 📌 Contexte
Mission réalisée pour le service **Clients & Performances Commerciales de SFR**.  
Objectif : construire un **reporting Excel** permettant d’analyser les clients, le réseau 5G et les performances commerciales.

---

## 🎯 Objectifs

### 🔹 Analyse Clients
- Répartition des modes de paiement  
- Analyse du churn (volumes + % par motif)

### 🔹 Consommation Réseau
- Évolution du nombre d’antennes 5G (2023 → 2024)  
- Évolution du taux d’utilisation 5G par région

### 🔹 Performances Commerciales
- CA et satisfaction par canal (Boutique, Téléphone, Web)  
- Analyse des vendeurs selon leur taux de réduction (>10 %, >15 %, >20 %)

### 🔹 Reporting
- Création d’un onglet **Reporting** clair  
- Export PDF pour présentation

---

## 🛠️ Compétences mobilisées
Excel (TCD, Power Query), analyse de données, KPI, storytelling, mise en forme professionnelle.

## 📄 Livrables

- Export PDF
